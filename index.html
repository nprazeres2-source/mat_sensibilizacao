Só neste dispositivo

Toque numa célula para registar ou anular a entrega desse material à pessoa. Toque no nome para editar a ficha.

Sincronização (Firebase)

Os dados ficam no projeto Firebase equip-campo, na coleção própria matsens (separada do registo de equipamento de campo). Todos os dispositivos ligados veem as mesmas alterações em tempo real e a app continua a funcionar sem rede, sincronizando quando a ligação voltar.

As contas de acesso (email e palavra-passe) criam-se na consola do Firebase → Authentication → Users → Add user.

Cópia de segurança

Os dados ficam guardados neste dispositivo/navegador. Exporte regularmente uma cópia (JSON) e importe-a noutro equipamento para continuar o registo.
